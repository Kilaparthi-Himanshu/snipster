# SNIPSTER 2.0 — INSTALLATION GUIDE

Thank you for installing Snipster!

## INSTALLATION

1. Extract all files into a folder.
2. Double-click **Install Snipster.bat**.
3. Approve the Windows administrator permission prompt.
4. Wait for the installation to complete.

Snipster will automatically launch after installation and appear in your system tray.

## USING SNIPSTER

- Default shortcut: **Win + Ctrl + Shift + S**
- Select an area of your screen to capture.
- The screenshot is automatically copied to your clipboard.
- Paste it anywhere using **Ctrl + V**.

## SYSTEM TRAY

Snipster runs in the background.

Right-click its system tray icon to:
- Open Snipster settings.
- Capture a screenshot.
- Exit Snipster.

## UNINSTALLATION

Double-click **Uninstall Snipster.bat** to remove Snipster.
